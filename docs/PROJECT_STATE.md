## Що це
Невеликий навчальний PHP-проєкт (php_lesson) — приклад простої форми входу
(login) на чистому PHP із версткою на Bootstrap 5. Публічний репозиторій,
ліцензія MIT (автор: Sych Mykola, 2025). README: "One of php lessons".

## Мета
Показати базовий навчальний приклад: HTML-форма логіну, обробка POST-запиту,
використання сесій PHP і перенаправлення (redirect) на захищену сторінку.
Призначення — демонстрація/навчання, не production.

## Що працює
- `index.php` — сторінка з формою входу; показує повідомлення про помилку з
  `$_GET['error']`. Синтаксис VERIFIED (`php -l` — No syntax errors).
- `login.php` — перевіряє логін/пароль проти захардкоджених значень
  (`admin` / `secret123`), заводить `$_SESSION['user']`, редіректить на
  `users.php`. Синтаксис VERIFIED (`php -l`).
- `users.php` — захищена сторінка; без сесії редіректить на сторінку входу.
  Синтаксис VERIFIED (`php -l`).
- Запуск у браузері через вбудований сервер PHP — UNVERIFIED (не запускалося
  в цьому аудиті; перевірявся лише синтаксис).

## Поточний стан
Три PHP-файли + README + LICENSE. Історія git: два коміти
("Initial commit", "Add project files"). Гілок окрім `main` немає.
Тести, CI, система збірки відсутні.

## Архітектура
Безфреймворковий PHP, кожен файл — окрема сторінка. Стан користувача — у
серверній сесії PHP (`session_start()`). Стилі — Bootstrap 5 з CDN.
Потік: `index.php` (форма) → POST → `login.php` (перевірка, сесія) →
`users.php` (захищена сторінка).

## Збірка / тести / запуск
- Збірка: не потрібна (інтерпретований PHP).
- Тести: відсутні.
- Запуск (орієнтовно, UNVERIFIED): `php -S localhost:8000` у корені репозиторію,
  відкрити `http://localhost:8000/index.php`.
- Перевірка синтаксису: `php -l <file>.php`.

## Наступні кроки
Можливі навчальні покращення (не виконувались у цьому аудиті):
- Прибрати захардкоджені облікові дані; перейти на хеш пароля
  (`password_hash` / `password_verify`).
- Виправити неузгодженість редіректів: `login.php` та `users.php` ведуть на
  `index.html?error=...`, але сторінка входу — `index.php` (файлу `index.html`
  немає). Див. "Відкриті питання".
- Додати CSRF-захист до форми логіну.

## Відкриті питання
- Редіректи у `login.php` та `users.php` вказують на `index.html`, якого в
  репозиторії немає (реальна сторінка — `index.php`). Імовірно, помилка:
  повідомлення про помилку входу не відобразиться. Виявлено з реального дерева,
  не з README.
- Мова проєкту: код, README і коментарі — англійською; автор — українською.
  Цей документ стану ведеться українською згідно з governance-конвенцією.
- `tools/project_guard.py` НЕ додано до цього репозиторію: це публічний
  навчальний репозиторій з одним автором, де механізм single-writer lock зайвий
  і лише ускладнив би приклад. Правила governance (AGENTS.md) усе одно додано;
  за потреби guard можна скопіювати пізніше з шаблону.
- Коректність роботи у браузері (сесії, редіректи) не перевірялася — UNVERIFIED.
